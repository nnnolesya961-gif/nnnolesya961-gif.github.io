# Портфолио Олеси — версия 0.2

Рабочий адаптивный сайт на HTML, CSS и JavaScript. Не нужны платные аккаунты, сборка, Node.js или Figma. Все ссылки между страницами относительные — сайт подходит для GitHub Pages.

## Как посмотреть

Открой `index.html` двойным кликом в браузере. Можно открыть `projects/uzum.html`, `projects/kaspersky.html`, `projects/projection.html`. GitHub Pages публикует эти файлы без сборки.

## Как добавить контакты

Открой `js/settings.js` и впиши настоящий адрес почты и Telegram. Пока поля пустые, неработающие ссылки скрыты — посетитель не попадёт в пустую заглушку. Почта после заполнения копируется кнопкой «Скопировать почту» в левой панели и в мобильном меню.

## Как поставить свои шоты

Положи файлы в папку `images` (PNG, JPEG или WebP). В `js/settings.js` впиши пути, например:

```js
images: {
  uzum: 'images/uzum.webp',
  kaspersky: 'images/kaspersky.webp',
  projection: 'images/projection.webp',
  food: 'images/food.webp',
  fitness: 'images/fitness.webp',
  breathe: 'images/breathe.webp',
  kanban: 'images/kanban.webp'
}
```

Существующие обложки созданы кодом как временные демонстрационные визуалы. Они не являются оригинальными экранами проектов. Когда укажешь свой файл, он **показывается полностью (`object-fit: contain`)**, без обрезания. Для качественной обложки лучше подготовить композицию в 1600–2400 px по длинной стороне; это рекомендация, не техническое требование.

## Изменить главный текст

В файле `index.html` найди `data-hero-copy`. Внутри указаны `data-full` и `data-short` — полный и короткий текст. Кнопка-колесо справа вращается и переключает текст, но высота hero остаётся неизменной.

## Шрифт

Во всех компонентах указан **Open Sans**. Загружается через Google Fonts. Если пользователь не может открыть Google Fonts, браузер временно покажет системный `sans-serif`. Для полностью автономной версии позже понадобится самостоятельно подключить webfont из легального источника к хостингу (этот архив не включает файлы шрифтов).

## GitHub Pages — без командной строки

1. В GitHub нажми **New repository**.
2. Назови репозиторий `<твой-логин>.github.io`, выбери **Public**.
3. Открой репозиторий, затем **Add file → Upload files**. Перетащи **содержимое** распакованной папки (включая `index.html`, `css`, `js`, `projects`, `images` и `.nojekyll`), а не ZIP целиком.
4. **Commit changes**.
5. В **Settings → Pages**, в разделе Build and deployment выбери **Deploy from a branch**, затем ветку `main`, папку `/(root)` и нажми Save.
6. Открой `https://<твой-логин>.github.io/` после успешной публикации. Иногда обновления появляются не мгновенно.

Позже менять сайт можно прямо на GitHub, редактируя файл и нажимая **Commit changes**, или через локальный редактор и Git.

## Что намеренно не добавлено

Нет внешних JavaScript-библиотек, React, платного хостинга, выдуманных контактов, вымышленных результатов проектов. Нет раздела «Немного обо мне» или второй контактной секции. Внутренние страницы пока являются структурным каркасом кейсов и требуют настоящих экранов.
